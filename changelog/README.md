# Changelog

This project uses tagged releases for meaningful guide milestones. Small source,
wording, and link-maintenance changes can ship between releases.

## v0.1.0 - 2026-08-17

Initial public field guide release.

### Included

- first-48-hours journey from application through support readiness;
- Microsoft for Startups program and portal navigator;
- company-backed identity and administrative continuity guidance;
- cost guardrails and graduation planning;
- startup-sized platform foundation;
- Azure Container Apps versus Azure Kubernetes Service decision record;
- curated official and community resource paths;
- four accessible, responsive SVG decision diagrams;
- contribution, editorial, governance, security, and conduct policies; and
- automated Markdown and external-link validation.

Technical and program claims were reviewed against current official Microsoft
documentation on August 16-17, 2026. Time-sensitive program, pricing, quota,
region, support, and Preview information must still be checked at the linked
