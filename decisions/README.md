# Technology decisions

This section will contain concise decision records for choices that startups
frequently make too early or revisit too late.

Every decision page must include:

1. the problem being solved;
2. a startup-stage default;
3. requirements that justify each option;
4. cost and operational tradeoffs;
5. conditions that invalidate the recommendation; and
6. official sources.

## Planned decisions

- Azure Container Apps vs. Azure Kubernetes Service
- Bicep vs. Terraform
- Azure SQL vs. PostgreSQL vs. Cosmos DB
- Single-tenant vs. multitenant SaaS
- Consumption vs. reserved capacity
- Managed service vs. self-hosted component

These pages will not declare universal winners. They will make the default,
exceptions, and revisit triggers explicit.
