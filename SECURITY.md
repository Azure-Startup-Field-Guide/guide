# Security policy

## Reporting a vulnerability

Do not open a public issue for:

- credentials, tokens, recovery codes, or personal data;
- a vulnerability in a linked project;
- a vulnerability in an Azure or Microsoft service; or
- customer-specific architecture or incident details.

For vulnerabilities in this repository's code or automation, use GitHub's
private vulnerability reporting feature when enabled, or contact the
maintainers privately through the organization profile.

For Microsoft product security issues, follow the
[Microsoft Security Response Center reporting process](https://www.microsoft.com/en-us/msrc/faqs-report-an-issue).

For a linked community project, follow that project's security policy.

## Scope

Documentation errors that could cause insecure deployments may be reported as a
normal issue if the report contains no sensitive information. Clearly describe
the risk and link to the current official security guidance.
